# UI参照画像と画面の対応表

**更新:** 2026-09-27  
**正本:** `02_ui_screen_spec.md` の画面ID・状態・遷移。画像はapp-owned領域の見た目の基準。端末枠、ステータスバー、ホームインジケータは再現対象外。

## 比較の基準

- 画面モック16点はすべて941×1672pxの画像。端末モデルと実際のポイント寸法は画像から確定できない。まずExpo Webの390×844で配置を比較し、最終的には使用するiPhoneのExpo Goで同じ状態を撮影して比較する。
- 2点の画面・フロー図は1800×1100px、旧構成図は1673×923px。これらは画面デザインではない。
- 共通要素は白い背景、紺の見出し、青い操作色、薄い青灰の面、上部ブランド、下部5タブ、線画アイコン。現在の実装色は `apps/mobile/src/ui/theme.ts`、書体はiOS標準フォント。画像の文字・アイコン・余白は実機比較時に画面ごとに採寸する。
- 投稿やユーザーの写真・件数・名前は画像内の例示。検証中に架空の交流や件数を実データとして表示しない。

## 画像のない画面・状態

- AUTH-001 / AUTH-002、ONB-001 / ONB-002 / ONB-004 / ONB-005には専用の画面画像がない。共通の白・青の体系で作り、認証・年齢・同意の順序は正式仕様に合わせる。現在のログイン・初期設定は開発プレビュー。
- DISC-002〜004、POST-002〜008・011、SOCIAL-001〜004、DM-004〜005、NOTI-002、SET-003〜006、SAFE-001〜002・005〜009、BILL-002〜005、SYS-001〜006、ADMIN-001〜009には専用画像がない。各フェーズで本文仕様から画面を定義する。
- 全画面共通: loading、empty、error、offline、permission denied。権限に関わる画面: private、teen、restricted、suspended。未認証・登録停止・アップロード失敗・通報後の状態も必要。完成判定は`02_ui_screen_spec.md`のUI Definition of Doneに従う。
